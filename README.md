# Luze Beauty

Web del estudio de uñas de Candela (Cande) en Mar del Plata. Es un sitio estático, sin dependencias: HTML, CSS y JS.

## Estructura

- `index.html` — la web
- `css/styles.css` — estilos (paleta "Luz cálida")
- `js/main.js` — filtros de la galería, sellos de fidelidad, animaciones al scrollear
- `assets/` — imágenes optimizadas, video y emojis que usa la web
- `servicios/` — fotos y videos originales de los trabajos
- `fotos/` — fotos de Cande
- `referencias-esteticas/` — inspiración visual
- `moodboard/` — propuesta estética
- `BRIEF.md` — todos los datos del negocio y decisiones de diseño

## Ver la web en tu compu

Abrí `index.html` en el navegador, o levantá un servidor local:

```
python3 -m http.server
```

y entrá a http://localhost:8000
